# Contributing

Thanks for your interest in contributing to cmake_helpers!

How to contribute:

1. Open an issue describing the bug or feature you want to propose.
2. Fork the repository and create a branch with a descriptive name, e.g., `feat/add-finder` or `fix/typo`.
3. Make changes in your branch and include tests or examples where applicable.
4. Run any available linters or formatters (see `scripts/` if present).
5. Open a pull request that references the issue and describes the change.

Guidelines:

- Keep changes small and focused.
- Document any public helper macros/functions you add.
- Be respectful and follow the Code of Conduct.
